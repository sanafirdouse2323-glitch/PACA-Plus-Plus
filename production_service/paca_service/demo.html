PACA++ Gateway Console

Interactive client for the PACA-Plus-Plus authorization service. Explore its two-stage permit and protected-execution protocol using an isolated test instance.

Test-environment warning: Connect only to an isolated PACA++ test deployment. Use a short-lived test access token, never a production credential. The token is kept in this page only and is not written to browser storage. The resource identifier must already be provisioned by the server; this page cannot grant permissions or create trusted resource facts.
