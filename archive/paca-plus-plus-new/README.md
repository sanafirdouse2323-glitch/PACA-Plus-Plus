# PACA-Plus-Plus-New source archive

This directory preserves a text snapshot of `PACA-Plus-Plus-New` at commit `064d4f401ea460d7671f86d32d3b22eee4bed6a9` (branch `main`). The separate repository remains available at https://github.com/sanafirdouse2323-glitch/PACA-Plus-Plus-New.

- `original-README.md`: the README from the source repository.
- `snapshot/`: text contents of the source blobs plus the contents embedded in four malformed Git tree paths. These are archival text files, not importable Python modules.
- `RECOVERY_NOTES.md`: findings about the source layout and why the code is not merged as a working package.

The main repository's existing `compiler/`, `prototype/`, and `production_service/` were left unchanged. No claim is made that the archived code runs or that the two implementations are semantically equivalent.
